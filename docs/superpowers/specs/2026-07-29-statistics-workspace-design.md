# 数据统计工作台重构设计规格

## 背景

前两个阶段已经完成响应式课表工作台和学生工作台。现有统计页具备今日、本周、本月切换、收入趋势、学生排行、异常记录和导出能力，但仍存在以下问题：

- 页面由单个大型 `StatsPanel.vue` 承担全部计算、图表和展示职责。
- 指标层级较弱，无法快速回答“收入如何、工作量如何、完成情况如何、哪些学生需要关注”。
- 当前同期比较接口固定比较当前周或当前月，浏览历史周期时仍会显示当前周期对比。
- 前端缺少准确计算完成率和活跃学生数所需的聚合字段。
- 统计请求与课表请求绑定，其中一个请求失败可能导致整个 Dashboard 加载失败。
- 学生排行不能跳转到对应学生工作台。
- 移动端沿用桌面图表结构，阅读密度和触控体验仍可提升。

第三阶段采用已确认的 A“决策流布局”和“模块化渐进重构”路线，在不改变数据库结构与课程业务规则的前提下，形成综合经营概览。

## 目标

- 让教师在进入统计页后先看到关键经营结论，再查看趋势、学生贡献和异常记录。
- 准确展示实际收入、有效课时、课程完成率和活跃学生数。
- 让同期比较与当前查看区间一致，支持今日、历史周和历史月。
- 提供收入与课时趋势的桌面组合展示和移动端单指标展示。
- 点击学生贡献排行后进入并选中对应学生。
- 将统计数据加载与课表加载隔离，支持局部加载、错误保留和重试。
- 延续 Lumina 紫粉柔光视觉体系及暗色模式。

## 非目标

- 不修改数据库表结构。
- 不改变课程状态枚举、收入确认规则或自动完成规则。
- 不增加自定义日期范围、任意学生筛选或多维分析抽屉。
- 不增加 AI 洞察、预测收入或自动经营建议。
- 不重构系统设置页面。
- 不替换现有 Excel 导出格式。

## 已确认的设计方向

- 内容策略：综合经营概览。
- 交互深度：轻量联动。
- 页面布局：A“决策流布局”。
- 技术路线：模块化渐进重构。
- 后端范围：允许小范围扩展统计响应字段和比较参数，不修改数据库。

## 页面信息架构

统计页从上到下分为五个区域。

### 1. 顶部控制区

- 页面标题与当前统计区间。
- 今日、本周、本月切换。
- 本周和本月支持前一周期、后一周期及回到当期。
- 导出当前区间 Excel。
- 周期切换保持现有语义，不增加自定义日期选择器。

### 2. 核心指标区

展示四项指标：

1. 实际收入。
2. 有效课时。
3. 课程完成率。
4. 活跃学生数。

收入和课时展示同期变化；完成率展示已完成数量与统计分母；活跃学生展示本期覆盖人数。没有可靠比较数据时显示状态说明，不伪造百分比。

### 3. 趋势区

- 桌面端在一张宽幅图表中同时展示收入与课时。
- 收入使用紫粉面积线，课时使用低对比虚线。
- 鼠标悬停、键盘聚焦和手机点击趋势点时显示日期、收入、课时和课程数。
- 没有数据时显示明确空状态，不绘制伪造的零值趋势。

### 4. 学生贡献区

- 学生按实际收入降序排列。
- 每行显示学生色、姓名、收入、课时和相对贡献进度。
- 整行使用按钮或链接语义。
- 点击后进入 `/students?student=<id>`。
- 学生页面读取查询参数并选中有效学生；无效或已归档 ID 回退到第一位活动学生。

### 5. 需要关注区

- 展示统计周期内的请假和已调课记录。
- 每条记录显示状态、学生、日期、时间、课时和备注。
- 手机端默认展示最近三条，可展开全部。
- 该区域只读，不在统计页直接修改课程状态。

## 指标口径

### 实际收入

统计周期内状态为“已完成”的课程价格总和。

### 有效课时

统计周期内状态为“待上”或“已完成”的课程时长总和。请假和已调课的原课程不计入有效课时。

### 课程完成率

公式：

```text
已完成课程数 ÷（已完成课程数 + 待上课程数 + 请假课程数）
```

“已调课”的原课程不进入分母，避免与调课后的新课程重复计算。分母为零时完成率显示 `0%`，并标注“暂无课程”，不展示增长含义。

### 活跃学生

统计周期内至少存在一节“待上”“已完成”或“请假”课程的去重学生数。仅存在“已调课”原记录的学生不计入。

### 异常记录

状态为“请假”或“已调课”的课程记录。异常记录不计入实际收入；请假只进入完成率分母，已调课原课程不进入完成率分母。

## 同期比较规则

- 今日：与前一天比较。
- 当前周：从周起始日至今天，与上一周相同经过天数比较。
- 历史完整周：与前一完整周比较。
- 当前月：从月初至今天，与上月相同经过天数比较；上月天数不足时截到上月末。
- 历史完整月：与前一完整月比较。

前端将当前统计区间的 `from` 和 `to` 传给比较接口。后端基于该区间及粒度计算上一等价周期，避免历史页面继续显示当前周期数据。

增长率的分母为零时返回 `null`。前端显示“上期暂无数据”，不显示无穷大或 `100%`。

## 后端接口调整

### `GET /stats/range`

保持现有参数：

```text
from
to
granularity
```

在 `RangeStats` 中增加：

```ts
completed_lessons: number
pending_lessons: number
leave_count: number
reschedule_count: number
active_students: number
```

现有字段保持兼容：

```ts
total_income
total_hours
total_lessons
buckets
```

`total_lessons` 继续表示有效课程数量，即“待上”和“已完成”课程数之和，避免破坏已有调用方。

### `GET /stats/comparison`

调整为接收：

```text
from
to
period=day|week|month
```

响应继续返回收入、课时和课程数的当前值、上一期值及增长率。`period` 用于确定自然周期边界；`from`、`to` 用于支持当前未结束周期和历史周期。

为避免一次性破坏已有调用，后端可在过渡期保留缺少 `from`、`to` 时的当前周或当前月行为，但新前端必须始终传入明确区间。

### `GET /stats/students` 与 `GET /stats/leave`

不修改响应结构。学生排行继续按实际收入降序；异常列表继续按日期和时间倒序。

## 前端组件边界

### `StatsPanel.vue`

- 负责整体布局。
- 接收统计数据、加载状态和错误状态。
- 编排周期、导出、重试和学生跳转事件。
- 不实现复杂统计计算和 SVG 坐标计算。

### `StatsMetricGrid.vue`

- 展示四项核心指标。
- 接收格式化后的指标模型。
- 不请求数据。

### `StatsTrendChart.vue`

- 展示收入与课时趋势。
- 处理桌面双指标与手机单指标模式。
- 处理趋势点详情、图例和空状态。
- 发出移动端指标切换事件或在组件内部维护纯展示状态。

### `StudentContribution.vue`

- 展示学生贡献排行。
- 发出 `select-student(studentId)`。
- 使用可访问的按钮或链接语义。

### `AttentionList.vue`

- 展示请假和调课记录。
- 在手机端维护“显示三条 / 展开全部”的纯展示状态。

### `statsWorkspace.ts`

提供纯函数：

- 计算完成率。
- 格式化增长文案和语义色。
- 将后端 bucket 转换为连续趋势点。
- 构建指标展示模型。
- 计算学生相对贡献比例。
- 裁剪移动端默认异常记录。

上一等价区间由后端作为唯一权威来源计算，前端不重复实现同期日期规则。

### `DashboardPage.vue`

- 保存统计数据、加载状态、错误信息和请求序号。
- 在进入统计页和切换周期时调用 `loadStatistics()`。
- 只接受最后一次统计请求的结果，防止快速切换造成旧响应覆盖。
- 处理导出失败提示。
- 处理学生跳转和 `/students?student=<id>` 的初始选择。

## 数据流

1. 用户进入 `/stats`。
2. `DashboardPage` 根据 `statRange` 和 `statsOffset` 计算 `from`、`to` 和粒度。
3. `loadStatistics()` 递增请求序号并并行调用：
   - `/stats/range`
   - `/stats/comparison`
   - `/stats/students`
   - `/stats/leave`
4. 仅当响应序号仍是最新序号时写入页面状态。
5. 成功数据传入各展示组件。
6. 周期切换时保留上一次成功数据并显示局部加载状态，避免页面闪空。
7. 请求失败时保留旧数据，展示“当前区间更新失败”和重试入口。
8. 点击学生贡献行后导航到 `/students?student=<id>`。
9. 学生列表加载完成后，优先使用有效查询参数；否则使用当前有效选择或第一位活动学生。

`todayStats` 可继续由 Dashboard 用于课表首页，但统计工作台的区间指标以 `RangeStats` 为准，避免同一指标出现两个数据来源。

## 请求隔离

- 统计请求不再作为课表主体请求成功的前置条件。
- 课表、学生目录和统计各自维护错误状态。
- 第三阶段只拆出统计加载流程，不全面重写 Dashboard 的所有请求架构。
- 离开统计页时无需取消已发请求，但请求序号必须阻止过期响应覆盖状态。

## 响应式规则

### 桌面端（`>= 1024px`）

- 四项指标单行排列。
- 趋势图占据整行。
- 下方采用约 `60% / 40%` 的学生贡献和需要关注双栏。
- 页面最大宽度延续现有 AppShell 内容约束。

### 手机和平板（`< 1024px`）

- 指标使用两列网格；极窄宽度仍保持可读数字，不强制单列。
- 周期选择与日期导航分为两行。
- 所有主要按钮触控区域不小于 44px。
- 趋势图默认突出收入，通过“收入 / 课时”切换指标。
- 图表不使用横向滚动，按可用宽度减少横轴标签密度。
- 学生贡献使用进度条列表。
- 需要关注默认显示最近三条，可展开全部。
- 页面底部保留移动导航与 safe-area 空间。
- 390px 宽度下不得产生横向溢出。

## 视觉规范

- 延续紫色 `#7c3aed`、粉色 `#ec4899` 和 Lumina 柔光背景。
- 指标卡使用统一的中性色底与单一语义强调，不为每项指标分配无关的高饱和颜色。
- 正向增长使用绿色，下降使用红色；无比较数据使用中性色。
- 趋势主线使用紫粉渐变，次要课时线降低饱和度与线宽。
- 学生个人颜色只用于头像和贡献条的小面积强调。
- 卡片圆角、边框、阴影和暗色模式沿用前两个阶段的设计变量。

## 错误与空状态

- 首次加载：指标和图表显示局部骨架。
- 周期刷新：保留旧数据并显示轻量加载条。
- 全部统计请求失败：显示统计错误卡和“重新加载”按钮。
- 部分区域无数据：对应组件显示自己的空状态，不隐藏其他成功区域。
- 导出失败：显示“导出失败，请稍后重试”。
- 完成率分母为零：显示 `0%` 和“暂无课程”。
- 学生查询参数无效：回退到第一位活动学生。
- 学生排行为空：显示“当前周期暂无学生贡献数据”。
- 异常列表为空：显示“当前周期没有请假或调课记录”。

## 可访问性

- 周期切换使用按钮语义并暴露当前选中状态。
- 趋势图提供可读标题和数据摘要；趋势点支持键盘聚焦。
- 不仅通过颜色表达增长、下降和课程状态。
- 学生排行整行可聚焦，并提供“查看某某学生”可访问名称。
- 图标按钮提供可访问名称。
- 焦点样式沿用全局焦点环。
