# 响应式课表工作台设计规格

## 背景与依据

本规格整理自已经确认的两组设计记录：

- `.superpowers/brainstorm/ui-reference-20260728/content/responsive-dual-v3.html`
- `.superpowers/brainstorm/update-plan-20260728/content/mobile-status-options.html`

页面设计事件记录已确认采用“响应式双端方案 V3”；移动状态交互最终选择 A：“点击课程 → 底部操作面板”。

## 目标

把现有课表首页更新为 Lumina 紫粉柔光视觉体系，并针对桌面与手机使用方式分别组织信息：

- 桌面端以完整周课表和侧边概览为核心。
- 手机端以当天课程、日期切换和单手操作为核心。
- 点击手机课程卡片后，从底部弹出状态操作面板；操作成功后立即刷新课程与统计。
- 保留现有月/周/日切换、拖拽排课、批量操作、备注、导出、学生、统计和设置能力。

## 视觉系统

- 主色：紫色 `#7c3aed`，辅助粉色 `#ec4899`。
- 主按钮与品牌标识使用紫粉渐变。
- 页面背景使用低对比紫、粉径向柔光；主体卡片保持半透明白色与轻量阴影。
- 正文使用深紫灰，次级文字使用中性紫灰。
- 卡片圆角 16–24px；桌面控件保持紧凑，移动端交互热区不小于 44px。
- 暗色模式继续可用，并使用同一语义色变量映射到深色背景。

## 信息架构

### 桌面端

1. 左侧固定导航：
   - Lumina 品牌标识。
   - 课表、学生、统计、设置。
   - 底部展示本月已完成课程数。
2. 内容顶部：
   - 面包屑。
   - 季节/日期提示。
   - 根据当前时间显示问候语与教师姓名。
   - “新建课程”主按钮。
3. 主工作区：
   - 左侧为月/周/日课表主体。
   - 周视图右侧显示今日课程数、完成进度、下一节课和活跃学生数。
   - 原有视图切换、导出和批量操作继续保留。

### 手机端

1. 顶部显示 Lumina 品牌、日期、问候语与头像。
2. 展示“今日课程”渐变摘要卡与完成进度。
3. 周视图只展示当前选中日期的课程流，并提供七天日期条切换。
4. 右下角提供悬浮新建按钮。
5. 底部保持四项导航，并升级为悬浮玻璃样式。
6. 点击课程卡片打开底部操作面板，而不是在卡片内堆叠状态按钮。

## 组件边界

- `AppShell.vue`：品牌、桌面导航、移动底栏、内容容器；接收本月完成数用于桌面摘要。
- `ScheduleDashboardHeader.vue`：桌面/移动问候、日期信息、今日摘要和新建入口。
- `ScheduleOverview.vue`：桌面右栏的今日概览、下一节课和活跃学生。
- `ScheduleBoard.vue`：桌面周网格和手机单日课程流；手机端只负责选择课程，不直接改变状态。
- `MobileLessonActionsSheet.vue`：手机底部操作面板；根据课程状态展示完成、请假、恢复、调课、编辑、日历和删除操作。
- `scheduleDashboard.ts`：问候语、今日课程、完成率、下一节课等纯计算逻辑，供组件与测试共用。
- `DashboardPage.vue`：数据请求、页面状态和组件事件编排。

## 数据流

1. `DashboardPage` 继续并行加载周课程、学生和统计数据。
2. 纯计算函数从现有 `lessons`、`students`、`todayStats` 派生展示数据，不增加后端接口。
3. 手机课程卡片点击后，将课程写入 `mobileActionLesson` 并打开底部面板。
4. 状态操作调用现有课程 API。
5. API 成功后关闭面板并重新执行 `loadDashboard()`，从而同步更新课程列表、今日摘要和统计。
6. API 失败时保留面板或给出已有错误提示，不进行乐观伪更新。

## 响应式规则

- `< 1024px`：隐藏桌面侧栏和周时间网格，显示手机/平板单日课程流与底部导航。
- `>= 1024px`：显示侧栏、周时间网格和右侧概览；隐藏手机摘要、悬浮按钮和底部操作面板。
- 手机日期条显示一周七天并允许点击；默认选中今天，如当前周不含今天则选中该周第一天。
- 页面不得出现横向溢出；底部面板与导航需尊重 iOS safe-area。

## 错误与无数据状态

- 今日无课：摘要显示 0 节与 0%，课程流显示明确空状态。
- 下一节课不存在：显示“今日课程已结束”或“暂无待上课程”。
- 学生信息缺失：使用“学生 #ID”和默认紫色。
- 状态操作失败：复用全局错误区或 toast，课程数据保持服务端最后一次成功状态。
- 删除操作继续要求确认。

## 测试与验收

- 纯逻辑单元测试覆盖问候语、默认选中日期、完成率和下一节课。
- 组件测试覆盖移动课程点击打开面板、不同状态的操作集合及操作事件。
- `npm run build` 必须通过。
- 浏览器分别以桌面 1440×900 和手机 390×844 验证：
  - 视觉层级与 V3 参考稿一致。
  - 桌面周视图、侧栏概览可用。
  - 手机单日流、日期切换、悬浮新建和底部导航可用。
  - 手机状态更新后课程卡片和统计立即变化。

## 非目标

- 不修改数据库结构或后端 API。
- 不在本阶段重做学生、统计、设置页面的信息架构。
- 不引入通知、搜索或真实头像上传功能。
- 不改变课程状态枚举和现有业务规则。
